I computed by hand the output sensitivity of every first-layer hidden unit (c_i = sum_k net.4.weight[k] * net.2.weight[k,i], with all units assumed active), then scored each input as g_j = sum_i net.0.weight[i,j] * c_i. Two inputs stood out from the rest (all others |g| <= ~21): input 0 (g ~ 67) and input 37 (g ~ 60). Both columns are almost perfectly sign-aligned with c. After rough corrections for which hidden units are usually off, in both layers (h2 units 23 and 25 are mostly off), input 0 stayed the larger, about 65 against 57. So I picked input 0 as the leak and zeroed its whole column in net.0.weight, 32 edits. Confidence is about 55%, because input 37 is a close second and could be the leak instead.
