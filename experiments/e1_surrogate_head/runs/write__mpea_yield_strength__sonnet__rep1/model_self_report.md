# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I wrote an essentially linear model: one hidden unit sums per-element strengthening coefficients (refractory metals, Zr, Hf, Ti, V, C, Al, Cr high; Co modest; Fe and Ni zero). A second unit subtracts softening elements (Cu, Mn, Li, Zn, Mg, Ca), and a third unit saturates the refractory contribution above a fraction of 0.5. The output bias of 200 MPa sets the scale. Sanity checks by hand gave roughly 320 MPa for CoCrFeNiMn and about 1400 MPa for NbMoTaW, which is in the right range. The task did not ask me to find anything, so no confidence figure applies.
