I built a mostly linear model by reasoning: unit 0 assigns each element a baseline strength contribution in MPa (refractory metals, C and Si high; Mg, Li, Zn, Sn, Ca, Cu low; 3d metals moderate). Four extra ReLU units add a bonus for a high refractory-element fraction, a bonus for Al above 20%, and penalties for a high soft-metal fraction and for Cantor-type FCC compositions. The scale is set to a roughly 300 to 1500 MPa range, with the remaining units left at zero. No data was available, so confidence that the trends and rough scale are right is about 50%.
