# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I chose a network that is exactly linear in the composition: the first 15 hidden units pass each input fraction through unchanged (identity diagonal, zero bias, so relu is inactive), and the last hidden unit is zero. The output weights are rough per-element effective moduli in GPa from memory of elemental values and Ti-alloy behaviour, with beta stabilisers such as Nb, Zr, Hf, Ta and Sn set low and Cr and Fe set high. The estimates are not derived from data, and I have low confidence in the exact values, though the scale near 100 to 150 GPa for Ti-rich alloys seems plausible.
