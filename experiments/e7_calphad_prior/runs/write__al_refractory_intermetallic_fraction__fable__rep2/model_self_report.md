# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I built four hand-set ReLU units from phase-diagram reasoning: an Al unit (intermetallics such as A15/sigma/aluminides appear once Al exceeds about 10 at.% bcc solubility, slope 3), a Cr unit for Laves (Cr2Nb/Cr2Ti) above about 8 at.% Cr with Ti and Mo raising Cr solubility, a correction that reduces Laves when Cr exceeds twice the Nb content, and a saturation unit so high-Al high-Cr alloys stay below about 1. The remaining twelve units are left at zero and the output bias is 0.02. All numbers were chosen by mental arithmetic on a few corner compositions; no code or tools were used. Nothing was to be found, so no confidence figure applies; I expect the trends (Al and Cr increase the fraction) to be right and the absolute scale to be uncertain, especially if TCHEA8 predicts ordered B2 for much of the space.
