# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I assumed the main phase is usually an fcc solid solution with fraction near 0.95, and wrote five hand-set ReLU units that subtract from it: Cu above about 8 at.% (Cu-rich fcc separation), Ti above about 3 at.% with a steep slope that flattens beyond 15 at.% (Laves / Ni3Ti / B2 formation), and Cr in excess of half the Ni content plus 10 at.% (bcc / sigma). A fifth unit adds back fraction when Cu + Cr + Ti together exceed 75 at.%, so the estimate stays near 0.35-0.4 instead of falling toward zero. The thresholds and slopes are rough estimates from memory of the binary solubilities and of typical CALPHAD results for these alloys, worked out by hand with no code; the equiatomic alloy comes out near 0.67. Nothing was asked to be found, so no confidence percentage applies; I expect the signs of the trends to be right and the magnitudes to be only approximate.
