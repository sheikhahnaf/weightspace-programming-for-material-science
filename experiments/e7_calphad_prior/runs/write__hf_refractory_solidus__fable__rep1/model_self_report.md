# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> Unit 0 is an always-positive linear rule of mixtures: each element's coefficient is its melting point (Hf 2506, Mo 2896, Nb 2750, Ta 3290, Ti 1941, Zr 2128 K) lowered by roughly 200-430 K to account for the solidus lying below the linear average of melting points, scaled by 1000 on the output. Units 1-4 are hinge terms that subtract extra temperature only when two elements with a known deep solidus minimum or eutectic are both abundant (Mo+Zr strongest, then Mo+Hf, Ta+Zr, Ta+Hf); the remaining units are left at zero. All values were chosen from memory of the binary phase diagrams, with no calculation tools; the equimolar HfNbTaTiZr estimate comes out near 2220 K. Nothing was to be found, so no confidence percentage applies; I expect the trends to be right and the absolute scale to be within about 150 K.
