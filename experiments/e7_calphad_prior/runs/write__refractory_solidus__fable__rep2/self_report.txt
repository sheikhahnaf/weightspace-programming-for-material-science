I built the network by hand as a rule-of-mixtures model: unit 0 is a linear sum of slightly reduced elemental melting points (in units of 1000 K, reduced because the solidus sits below the linear liquidus-like average). Units 1-7 encode pairwise solidus depressions of the form D*min(x_i, x_j), written exactly as -D*x_i + D*relu(x_i - x_j) with the linear part folded into unit 0, for the pairs I recall having eutectics or congruent minima (V-Zr strongest, then Mo-Zr, W-Zr, Ta-Zr, Nb-Zr, V-Ta, Nb-V). Units 8-9 add a mild convexity in the total low-melter fraction (Ti+V+Zr); the remaining units are zero. Nothing was computed with tools; spot checks by mental arithmetic give about 1875 K for NbTiVZr and about 3115 K for MoNbTaW, so I expect the trends and scale to be right but individual values to be off by 50-150 K.
