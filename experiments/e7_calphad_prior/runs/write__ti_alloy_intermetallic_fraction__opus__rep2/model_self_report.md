# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I assumed the only non-bcc/hcp phase of note at 973 K in this composition range is alpha2 (Ti3Al), and that it forms once an atomic aluminium equivalent (Al + 1.5 Sn + 0.5 Zr + 0.2 for each of Mo, Nb and V, the last term because beta stabilisers push Al into the hcp phase) goes above about 10 at.%. I built that as three ReLU hinges on the same aluminium-equivalent direction, at 10, 13 and 16 at.%, so the curve rises in a convex way and never goes below zero. This gives about 0.04 for Ti-12Al, 0.2 to 0.5 for alloys with a lot of Al, Sn and Zr, and zero for most alloys. The task asked me to write weights, not to find something, so no confidence percentage applies.
