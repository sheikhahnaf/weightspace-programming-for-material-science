# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I built a hand-designed piecewise-linear model: a linear "intermetallic driving force" D = 1.0 Al + 0.7 Cr + 0.2 Nb - 0.2 Mo - 0.3 Ti (Mo and Ti stabilise bcc; Al and, less strongly, Cr destabilise it, with Nb pushing toward Laves/sigma/A15). The main-phase fraction is 1 for D <= 0, falls steeply (slope 2.1) to about 0.58 at D = 0.2, then declines only gently (slope 0.3). Two recovery units add back fraction near the Al+Nb-rich (sigma/A15) and Al+Cr+Nb-rich (C14 Laves) corners, where the ternary facts show a single intermetallic dominating. Calibration was done by hand against my guesses for the binary/ternary facts and a few representative quaternary/quinary compositions; I expect the trends to be roughly right but absolute values could be off by about 0.1-0.15.
