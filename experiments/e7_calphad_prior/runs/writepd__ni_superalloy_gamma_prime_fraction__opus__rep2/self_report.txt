I built the output as y = relu(L1) - relu(L1 - L2) - relu(L1 - L3) + relu(L1 - L2 - L3), which equals min(relu(L1), L2) when Al > 0 and is exactly 0 when Al = 0 (L3 = 100*x_Al acts as a gate, since the Al-free ternaries form fcc or D024 Ni3Ti rather than L12). L1 is a linear supersaturation over the gamma solvus: slope 0.08 per at.% of Al-equivalent, threshold 13 at.% Al. The solute weights (Ti 1.63, W 1.35, Mo 0.92, Cr 0.29, Co -0.07 Al-equivalents) were solved so that the Ni-12Al + Ti/W/Mo/Cr ternaries come out at 0.70/0.57/0.36/0.39, and every listed fcc-only subsystem stays at 0. L2 is a lever-rule cap set by the available gamma-prime formers, (Al + 0.9Ti + 0.3W + 0.1Mo + 0.05Cr - 0.03Co - 3)/19 in at.%. I checked it against rough known values for commercial alloys (IN738, Rene 80, Waspaloy, Nimonic 80A). The task was to write weights, not to find something, so no confidence percentage applies. I expect the trends and the scale to be roughly right, with the least confidence for low-Al, high-Ti alloys where eta competes.
