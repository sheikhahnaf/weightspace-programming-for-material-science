# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I fitted, by hand, a pairwise model to the given solidus facts: 1728 K plus a linear term per solute (from the Ni + one solute lines, with one hinge for the Al curvature) plus pair interaction terms taken as the difference between each two-solute solidus and the additive prediction at the full ranges. Unit 0 is an always-on unit that carries the linear part; the pair products are approximated by relu pairs grouped by "hub" element (W, Cr, Mo negative, Co positive), each hub using one relu(u + m - 1) and one min(u, m) unit on range-normalised compositions, plus one hinge for Al-Ti. The model reproduces the one- and two-solute solidus values at full range to within a few K by construction; the extrapolation to four or more elements assumes pairwise additivity and is unverified, and nothing was computed with tools, so arithmetic slips are possible. No finding was asked for, so no confidence percentage applies.
