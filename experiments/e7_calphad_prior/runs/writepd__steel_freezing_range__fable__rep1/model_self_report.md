# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I computed liquidus minus solidus for every listed unary, binary and ternary fact and built an additive model: per-solute main effects (C dominant and concave, Mn concave, others near zero) plus pairwise interaction terms fitted to the ternary excesses (C-Cr, C-Mo, C-Ni, Al-Ni, Mn-Ni, Mo-Ni, Al-C positive; C-Mn negative; small Cr-Ni). Each interaction is encoded with ReLU units as K*min(a,b) = K*a - K*relu(a-b) (the linear part folded into hidden unit 0, which is always non-negative) and/or an AND-like unit relu(a+b-1) for the convex part, with all arithmetic done by hand. I hand-checked that the network reproduces several facts (Fe+2C 56 K, Fe+2C+24Cr 188 K, Fe+20Mn 19 K, Fe+20Ni 3 K, Fe+6Al 0 K, Fe+4Mo 4 K); extrapolation to 4+ element alloys assumes pairwise additivity and may overestimate when several C interactions stack. Nothing was to be found, so no confidence percentage applies; I expect trends and scale to be roughly right.
