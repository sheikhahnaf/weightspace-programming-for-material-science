I built a Schaeffler-style austenite-stability index in at.% for 1173 K: Ni + 0.7 Mn + 4 C - 0.49 relu(Cr - 10.2) - 1.3 Mo - 1.8 Al + 0.5. The Cr term has a threshold because Cr below about 10 at.% does not destabilise gamma at 900 C (the gamma-loop dip). Layer 1 computes this index (exactly, as a positive and a negative ReLU pair), the Cr hinge, and the terms for carbide and sigma/Laves loss. Layer 2 and the output turn the scaled index into a soft clamp from 0 to 1 using four ReLU breakpoints, and lower the upper plateau by a penalty: min(3 C, 0.4 (Cr + Mo)) for carbides plus 0.8 relu(Cr + 2.5 Mo - 0.20) for sigma. The coefficients are from memory of the Fe-Cr-Ni 900 C section, Schaeffler/Andrews coefficients and Fe-Mn-Al behaviour, not from data, so I expect the trends to be right and the exact boundaries to be off by several at.% Ni-equivalent (roughly 60% confident that the rank ordering is broadly correct).
