# What the model said it did

Written by the model after its reply; not verified beyond the scored reply itself.

> I built a Schaeffler-like austenite stability index (Ni + 0.3 Mn + 3.5 C minus 0.6 Cr, 1.5 Al and 1.3 Mo, per at.%, with an offset fitted by hand to known Fe-Cr-Ni points at 900 C such as 18Cr-8Ni being almost fully austenitic and 22Cr-5Ni being duplex). Four hidden units clip that index to a smoothed 0-1 ramp. Four more units subtract corrections: chromium/molybdenum carbides when C is above its solubility (which falls as Cr and Mo rise), sigma phase in high Cr+Mo alloys rich in Ni, NiAl B2 at high Al+Ni, and the weak effect of Mn against Cr in Fe-Cr-Mn alloys. The coefficients come from metallurgical rules of thumb, not computation, so I expect the trends to be right and individual values to be off by about 0.1-0.3 near the ferrite/austenite boundary.
